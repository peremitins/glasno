# Миграция БД (dev)

⚠️ Только для локальной разработки.

## Шаг 1: Проверь изменения в схеме

```bash
git diff server/infrastructure/db/schema.ts
```

Если изменений нет — спроси пользователя, уверен ли он, что миграция нужна.

## Шаг 2: Сгенерируй миграцию

```bash
pnpm db:generate
```

Покажи, какие SQL-файлы появились в `server/infrastructure/db/migrations`, и кратко — что они делают.

## Шаг 3: Примени миграцию

```bash
pnpm db:migrate
```

## Шаг 4: Проверка совместимости

Напомни о правилах обратной совместимости: не удалять/не переименовывать поля без переходного периода; новые поля добавлять, старые оставлять (на проде могут работать старые клиенты — web и Telegram).
