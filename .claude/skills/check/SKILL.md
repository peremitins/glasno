# Преддеплойная проверка

Запусти все проверки и выдай сводку.

## Шаг 1: Запусти параллельно

1. **Lint**: `pnpm lint`
2. **TypeScript**: `npx tsc --noEmit` (или `pnpm typecheck`)
3. **Тесты**: `pnpm test --run` (если тесты есть)
4. **Git**: `git status`

## Шаг 2: Сводка

По каждому пункту — статус (✅/⚠️/❌) и краткая суть проблем. Итоговый вердикт: можно ли коммитить/деплоить и что починить.
