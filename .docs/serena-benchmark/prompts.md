# Serena benchmark: фиксированные prompts

Для каждого prompt запускайте отдельную чистую сессию. Нельзя менять текст между baseline и Serena-прогонами. Каждый сценарий запускайте не менее трёх раз в каждом режиме.

1. `В app/pages/interview/[id].vue найди основной символ, отвечающий за работу интервью. Покажи его definition, все статические references и файлы, которые нужно прочитать перед безопасным изменением.`
2. `Найди useAuthStore: укажи definition, статические места использования в app и зависимости, которые нужно проверить перед изменением авторизации.`
3. `Проследи статически разрешимую часть вызова useAPI от Vue-компонента до server/api и application service. Явно назови границу, где начинается Nuxt или runtime-связь.`
4. `Найди shared/dto/interview.ts, перечисли статические imports и references его экспортов и укажи, какие сериализационные или строковые связи LSP не может подтвердить.`
5. `Подготовь preview переименования одного безопасного локального TypeScript-символа, используемого из Vue и standalone .ts: перечисли затрагиваемые места, но не применяй изменения.`
