# Изменения: защита роутинга, роли, учёт токенов, фиксы ревью

*Что сделано в этом блоке + что нужно запустить.*

---

## 1. Защита роутинга (как во взрослом продукте)

- `app/middleware/auth.global.ts` — глобальный guard. Неавторизованного редиректит на `/auth?next=<откуда пришёл>`; авторизованного уводит с `/auth`. Работает через httpOnly-cookie сессии (`/api/auth/me`).
- `app/pages/auth.vue` — экран входа по email-коду (без отдельной регистрации: первый вход создаёт аккаунт). Telegram-вход подключим в Фазе 8 (нужен бот).
- Публичные маршруты: только `/auth` и `/auth/link`. Всё остальное требует входа.

## 2. Роли user / admin

- В БД уже есть `users.role`. Admin выдаётся **автоматически при входе** по allowlist из env:
  - `ADMIN_EMAILS` (через запятую) — в `.env.development` уже стоит `peremitinns@gmail.com`.
  - `ADMIN_TELEGRAM_IDS`.
- **Admin = без лимитов** на AI: `BillingAccessService` отдаёт `unlimited:true`, лимит бесплатных сессий игнорируется. Чтобы стать админом — войди тем email, что в allowlist.

## 3. Учёт токенов и стоимости AI

- Таблица **`ai_usage`** — одна строка на каждый вызов модели: пользователь, сессия интервью, тип (`question_gen`/`answer_eval`/`report`/…), модель, входные/кэш/выходные токены, латентность, requestId, **costUsd** и сырой ответ. Запись fire-and-forget (не ломает основной поток).
- Таблица **`ai_model_pricing`** — прайс-лист (USD за 1M токенов/символов), источник истины для расчёта стоимости. Заполняется из кода (`server/application/aiUsage/pricing.ts`).
- Стоимость считается автоматически при каждом вызове (`computeCostUsd`).
- Подключено в движках: генерация вопросов, оценка ответа, отчёт. TTS/Realtime (аудио) — задел есть в схеме, подключим при необходимости (там тарификация по аудио/секундам).

> Цены gpt-4o-mini точные ($0.15/$0.60 за 1M). Для realtime/tts стоят ориентиры с пометкой `verify` — сверь с https://developers.openai.com/api/docs/pricing и поправь строки в `ai_model_pricing` (таблица редактируемая).

## 4. Фиксы из ревью

- 🔴 **YooKassa webhook** — теперь не доверяет телу запроса: подтверждает платёж **обратным запросом** `GET /v3/payments/{id}` и сверяет статус + сумму перед выдачей подписки. Грант идёт по данным заказа из нашей БД, а не из payload.
- 🟡 **CSRF для anon** — с жёстким login-гейтом весь трафик теперь авторизован (+ `SameSite=Lax` на анон-cookie). Риск закрыт на уровне доступа. Если позже появятся платные действия до логина — включим CSRF и для anon.

## Что запустить (на маке)

```bash
# 1) применить новые таблицы (ai_usage, ai_model_pricing) и изменения схемы
pnpm db:generate
pnpm db:migrate

# 2) заполнить прайс-лист моделей
pnpm db:seed-pricing

# 3) перезапустить и проверить
pnpm dev
pnpm test:run   # прогнать тесты после правок
pnpm lint
pnpm typecheck
```

После этого: войди по `peremitinns@gmail.com` (dev-код покажется на экране входа) → станешь admin → лимиты сняты. В Drizzle Studio (`pnpm db:studio`) увидишь, как наполняется `ai_usage` с costUsd по каждому вызову.
