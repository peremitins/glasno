# Фаза 2 — дизайн реализации

## Цель

Сделать сквозной текстовый MVP интервью: пользователь задаёт источник вакансии, опционально добавляет резюме, получает первый вопрос, отвечает текстом, при необходимости получает один уточняющий вопрос и проходит сессию до конца. Все сессии и ответы привязаны к анонимной cookie-сессии из Фазы 1.

## Границы фазы

Входит:
- hh.ru-ссылка через официальный API `GET /vacancies/{id}`;
- ручной текст вакансии или профессия без вакансии;
- извлечение текста резюме из `.txt` и `.pdf`;
- LLM-генерация вопросов по вакансии, резюме, роли, уровню, формату и режиму интервьюера;
- сохранение `interview_sessions` и `interview_turns`;
- API для создания сессии, просмотра текущего состояния и отправки ответа;
- минимальный веб-flow для прохождения интервью текстом.

Не входит:
- отчёт и BullMQ;
- голос, TTS, Zoom-режим;
- полноценная авторизация и перенос анонимной сессии в аккаунт;
- монетизация и лимиты;
- парсинг резюме по ссылке hh.ru и сторонних job-сайтов.

## Архитектура

Сервер остаётся в Clean Architecture:
- `shared/dto/interview.ts` задаёт контракты API и enum-значения.
- `server/application/interview/*` содержит сценарии: подготовка источника, создание сессии, приём ответа, выбор следующего вопроса.
- `server/interface/*` содержит порты для HH, LLM и репозитория интервью.
- `server/infrastructure/*` содержит реализации портов: Drizzle-репозиторий, HH HTTP-клиент, OpenAI LLM-провайдер, извлечение резюме.
- `server/api/interview/*` остаётся тонким слоем: DTO → application → DTO.

## Данные

`interview_sessions` расширяется под анонимный режим:
- `user_id` становится nullable до Фазы 4;
- добавляется `anonymous_session_id`;
- добавляются `vacancy_url`, `company_name`, `resume_raw`, `question_count`, `metadata`.

`interview_turns` расширяется под уточнения:
- `answer_transcript` хранит ответ пользователя;
- добавляется `kind`: `main` или `clarification`;
- добавляется `follow_up_for_turn_id` для связи уточнения с основным вопросом;
- добавляется `answered_at` и `metadata`.

## Логика интервью

1. Создание сессии нормализует источник:
   - `hh_url`: извлекает id вакансии из URL, запрашивает HH API, очищает HTML-описание;
   - `text`: берёт пользовательский текст вакансии;
   - `profession`: использует роль/специализацию без вакансии.
2. Сервис создаёт `interview_sessions` со статусом `running`.
3. LLM генерирует первый основной вопрос, сервис сохраняет его как `interview_turns`.
4. Пользователь отправляет ответ.
5. LLM оценивает, нужен ли один уточняющий вопрос:
   - если ответ поверхностный и у основного вопроса ещё нет уточнения, создаётся `clarification`;
   - иначе создаётся следующий `main`;
   - когда лимит основных вопросов достигнут, сессия получает статус `done`.

## API

- `POST /api/interview/sessions` — создать сессию и первый вопрос.
- `GET /api/interview/sessions/:id` — получить сессию и список реплик.
- `POST /api/interview/sessions/:id/answer` — сохранить ответ и вернуть следующий вопрос или завершение.
- `POST /api/interview/resume/extract` — принять файл резюме и вернуть извлечённый текст.

## Ошибки

Все ошибки идут через формат Фазы 1:
- `E_VALIDATION` — некорректный DTO, файл или источник;
- `E_AUTH` — отсутствует анонимная сессия;
- `E_FORBIDDEN` — попытка открыть чужую interview session;
- `E_NOT_FOUND` — session/turn/vacancy не найдены;
- `E_UPSTREAM` — ошибка HH API, OpenAI или PDF-извлечения;
- `E_UNKNOWN` — непредвиденная ошибка.

## Фронт

`/interview/new` становится рабочим мастером:
- выбор источника: hh.ru-ссылка, текст вакансии, профессия;
- параметры: роль, уровень, формат, режим интервьюера;
- поле резюме текстом и загрузка файла через API извлечения.

Новый экран `/interview/[id]` показывает:
- текущий вопрос;
- прогресс по основным вопросам;
- textarea ответа;
- историю вопросов и ответов;
- состояние завершения.

## Тестирование

Минимальный regression shield:
- unit-тесты нормализации HH URL/HTML;
- unit-тесты application-сервиса с fake repository и fake LLM;
- targeted typecheck/build после реализации;
- Drizzle migration generation после изменения schema.
