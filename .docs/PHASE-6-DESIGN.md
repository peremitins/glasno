# Фаза 6 — дизайн реализации

## Цель

Довести веб-версию до рабочего кабинетного интерфейса: пользователь видит прогресс, может продолжить активное интервью, запускать быстрые сценарии, проходить сессию в Zoom-подобном режиме с локальной камерой и управлением голосом, а также просматривать историю.

## Границы

- Фаза 6 не меняет LLM-логику интервью и отчётов.
- История и дашборд читают уже сохранённые `interview_sessions`, `interview_turns`, `interview_reports`.
- Камера работает только локально в браузере через `getUserMedia`; видео никуда не отправляется.
- UI использует существующий `useAPI`, i18n и текущую Nuxt-архитектуру.

## Backend

- Добавить read-model для кабинета:
  - summary: количество сессий, завершённые, средний балл, последний отчёт, активная сессия;
  - history: список интервью с прогрессом и данными отчёта.
- Расширить DTO:
  - `DashboardSummaryResponse`;
  - `InterviewHistoryResponse`.
- API:
  - `GET /api/dashboard/summary`;
  - `GET /api/interview/sessions/history`.

## Frontend

- `/` становится рабочим дашбордом:
  - активная сессия;
  - метрики прогресса;
  - последние правки из отчёта;
  - быстрые сценарии.
- `/interview/new` получает wizard-композицию и выбор аватара интервьюера.
- `/interview/:id` получает Zoom-подобную структуру:
  - карточка интервьюера с выбранным образом;
  - локальная камера;
  - вопрос, текстовый ответ, диктовка, TTS и realtime-panel;
  - история реплик.
- `/history` показывает реальные сессии, прогресс и CTA.

## Качество

- Адаптивность без перекрытий на мобильном.
- Все тексты идут через `app/i18n/locales/ru.json`.
- Состояния loading/empty/error явно отображаются.
