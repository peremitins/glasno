# ТЗ: Тарифы v2 — единый пропуск с выбором срока доступа

Статус: утверждено 2026-07-10. Реализация — отдельным этапом по этому ТЗ.

## 1. Причины ухода от текущей схемы

Сейчас на /pricing три карточки (Бесплатно / Разовая подготовка 399 ₽ / Pro 990 ₽мес) + пакеты минут. Проблемы:

1. **«Разовая подготовка» несправедлива по механике.** Списание «1 интервью» происходит в момент *создания* сессии без учёта статуса (`accessService.ts:137-154`): брошенное на первом вопросе интервью сжигает покупку; quick (3 вопроса, ~7 мин) стоит столько же, сколько deep (10 вопросов, ~25 мин); вторую сессию после брошенной создать нельзя.
2. **Срок действия (7 дней) нигде не указан** в карточке — претензии и возвраты.
3. **Двухосевой выбор** (какой тариф + фичи-сравнение) когнитивно тяжелее одноосевого («на сколько дней мне нужно»).
4. **Подписочная модель не совпадает с паттерном использования.** Подготовка к собеседованиям — эпизодическая: пользователь готовится к конкретному собесу/циклу поиска и уходит после оффера. Пропуска на срок честнее и снижают трение покупки.

## 2. Новая модель: «Полный доступ» с выбором срока

Один продукт. Внутри срока: **безлимит интервью всех форматов** (quick/standard/deep), голосовые минуты включены, разбор + PDF-отчёт, докупка минут. Текстовые интервью — без лимитов и fair-use (себестоимость ≈5–7 ₽ за deep-интервью на gpt-5.4-nano: $0.20/$1.25 за 1M токенов).

### Сетка (утверждена)

| Срок | Цена | ₽/день | Минуты голоса |
|------|------|--------|----------------|
| 7 дней | 449 ₽ | 64 | 30 |
| 15 дней | 899 ₽ | 60 | 60 |
| 30 дней | 1 190 ₽ | 40 | 60 |
| 90 дней | 2 290 ₽ | 25 | 60 |
| 180 дней | 3 490 ₽ | 19 | 60 |
| 365 дней | 4 990 ₽ | 14 | 60 |

Экономическое обоснование: голос (gpt-realtime, $32/$64 за 1M аудио-токенов, кэш input $0.40) ≈ **9–12 ₽/мин** блендед → 60 минут = 540–720 ₽ worst-case. Пол цены задаёт полное сжигание минут; 7-дневный пропуск получает 30 минут именно поэтому (недельные покупатели сжигают минуты активнее всех). Пакеты минут — апсейл с маржой ~25–40%.

### Пакеты минут — без изменений
+30/490 ₽, +60/890 ₽, +120/1 590 ₽; требуют активный платный доступ; живут, пока жив доступ.

### Free-тариф
Карточка «Бесплатно» удаляется со страницы тарифов. **Трайл остаётся**: 1 бесплатное quick-интервью (`FREE_SESSIONS_LIMIT`, логика не меняется) — как скрытый онбординг, а не «тариф».

## 3. Автопродление (критично, детально)

- **По умолчанию ВКЛЮЧЕНО** при покупке пропуска себе (любой срок).
- **Для подарка (`purchaseType: 'gift'`) — всегда ВЫКЛЮЧЕНО**, без опции включить при покупке; получатель может включить сам после активации.
- **Информирование при покупке**: под/рядом с кнопкой оплаты — текст вида «Продлевается автоматически: {дата} спишется {цена}. Отключить можно в любой момент в настройках» (i18n). Показывать в `BillingCheckoutModal.vue` и на карточке пропуска.
- **Тумблер в настройках**: блок «Текущий доступ» на /pricing уже содержит управление автопродлением и картой (`app/pages/pricing.vue:396-491`). Требования:
  - тумблер виден при любом активном платном доступе, включая случай «карта не привязана»: включение автопродления без карты запускает флоу привязки карты;
  - при покупке с автопродлением карта сохраняется в момент оплаты (`savePaymentMethod` у провайдера) — отдельная привязка не нужна;
  - выключение — мгновенное, доступ сохраняется до конца оплаченного срока; включение обратно — в любой момент до конца срока.
- **Механика продления**: `nextChargeAt = currentPeriodEnd`, продление на тот же срок по той же цене; исполняет существующий `billingRenewalWorker`. Предуведомление о предстоящем списании (email/Telegram): за 1 день для 7–15 дней, за 3 дня для 30+ дней — защита от чарджбеков и требование прозрачности.
- Блок `billing` в статусе уже отдаёт `nextChargeAt`, `nextChargeAmountRub`, `lastChargeError`, карту — переиспользуем.

## 4. Блок «Текущий доступ» (замена карточки Бесплатно)

Расширить существующий блок на /pricing (+ краткая сводка в `profile.vue`). Состояния:

1. **Трайл не использован**: «Бесплатный доступ: 1 быстрое интервью» + CTA «Пройти».
2. **Трайл исчерпан, доступа нет**: «Бесплатное интервью использовано» + CTA к выбору срока.
3. **Активный пропуск**: «Полный доступ · N дней», действует до {дата}; минуты: осталось X из Y; автопродление вкл/выкл (+ дата и сумма списания, карта •••1234); ошибки последнего списания.
4. **Пропуск истёк**: «Доступ закончился {дата}» + CTA «Продлить».

Данные уже почти все в `BillingStatusResponse` (`freeSessionsUsed/Limit`, `subscriptionExpiresAt`, `realtimeVoice`, `billing`); добавить `activePlanDurationDays` (или отдавать `periodDays` в публичном DTO плана — сейчас срезается в `toPublicPlan`).

## 5. Изменения по слоям

### `server/application/billing/plans.ts`
- Новые планы `pass_7d`, `pass_15d`, `pass_30d`, `pass_90d`, `pass_180d`, `pass_365d`: `kind: 'one_time'`, `includedInterviews: null`, `allowedSessionGoals: ALL`, `periodDays`/`priceRub`/`realtimeVoiceMinutes` по сетке, `isCheckoutEnabled: true`.
- Легаси: `free` (скрыть карточку — `isPublic: false`, логика трайла живёт отдельно от плана), `single_prep`, `pro_monthly` → `isPublic: false`, `isCheckoutEnabled: false`; выданные гранты обслуживаются, автопродления Pro продолжают работать.

### `server/application/billing/accessService.ts`
- One-time план с `includedInterviews === null` → полный доступ как у подписки (`canCreateInterview = true`, все `sessionGoals`, `paidInterviewsRemaining = null`). Числовой счётчик остаётся fallback-веткой для легаси `single_prep`.
- `hasActiveSubscription` семантически становится «есть активный платный доступ» — проверить все места использования (пакеты минут уже смотрят на «любой активный платный тариф»).

### `server/application/billing/billingService.ts` + `shared/dto/billing.ts`
- Checkout: параметр `autoRenew` (default `true`; принудительно `false` при `gift`); сохранение карты при оплате.
- Продление one_time-пропусков воркером при `autoRenew = true` (сейчас autoRenew завязан на kind subscription — обобщить на любой план с `periodDays > 0`).
- Публичный DTO плана: добавить `durationDays` для селектора.
- Подарки: фильтр `claimReadyGiftsByEmail` уже включает one_time-планы — новые пропуска дарибельны без доработок; грант из подарка всегда `autoRenew = false`.

### Фронт
- `app/pages/pricing.vue`: единый блок «Полный доступ» с селектором срока (слайдер или сегмент-контрол, 6 точек), реактивная цена + ₽/день, у 7 дней бейдж «30 минут голоса», кнопка оплаты + плашка автопродления. Карточки Free/Разовая/Pro удаляются. Блок пакетов минут остаётся. Блок «Текущий доступ» — по разделу 4.
- `app/components/billing/BillingCheckoutModal.vue`: строка автопродления (дата+сумма следующего списания) для покупки себе; для подарка — явное «без автопродления».
- `app/i18n/locales/ru.json`: все новые строки через i18n.
- `apps/landing/composables/useLandingContent.ts`: синхронизировать тарифный блок лендинга вручную (требование CLAUDE.md).

### БД
Миграции не требуются: `subscriptions` уже хранит `planId` строкой, `autoRenew`, `nextChargeAt`, `currentPeriodEnd`.
